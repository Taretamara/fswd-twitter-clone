# Twitter Clone Front-End Wireframes

## 1. Login / Signup Page

```text
+--------------------------------------+
|          Twitter Clone               |
|--------------------------------------|
|                                      |
|        [ Username / Email ]          |
|        [ Password ]                  |
|                                      |
|        [ Login Button ]              |
|                                      |
|        Don't have an account?        |
|        [ Sign Up ]                   |
|                                      |
+--------------------------------------+
```

## 2. Home Feed Page

```text
+--------------------------------------------------+
| Navbar: Home | Profile | Logout                  |
+--------------------------------------------------+
| What's happening?                                |
| [ Write a new tweet...              ]            |
| [ Post Tweet ]                                   |
+--------------------------------------------------+
| @username                                        |
| This is a tweet example.                         |
| [View Profile] [Delete if owner]                 |
+--------------------------------------------------+
| @anotheruser                                     |
| Another tweet appears here.                      |
| [View Profile]                                   |
+--------------------------------------------------+
```

## 3. User Profile Page

```text
+--------------------------------------------------+
| Navbar: Home | Profile | Logout                  |
+--------------------------------------------------+
| @username                                        |
| User profile information                         |
+--------------------------------------------------+
| Latest tweets by this user                       |
+--------------------------------------------------+
| Tweet 1                                          |
| [Delete if owner]                                |
+--------------------------------------------------+
| Tweet 2                                          |
+--------------------------------------------------+
```

## 4. Tweet Component

```text
+--------------------------------------------------+
| @username                                        |
| Tweet content goes here.                         |
| [Profile] [Delete]                               |
+--------------------------------------------------+
```

## 5. App Flow

```text
Login / Signup
      |
      v
Home Feed
      |
      |-- Click username
      v
User Profile Page

Home Feed
      |
      |-- Post tweet
      |-- Delete own tweet
      |-- Logout
```
